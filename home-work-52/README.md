# TruckLoads - Freight Management

React app for managing truck loads and freight.

## Installation

```bash
npm install
```

## Run

```bash
npm run dev
```

## Features

- View available loads
- Add new loads
- Filter by city
- Change load status
- Delete loads
- Toast notifications

## Tech Stack

- React + Vite
- Redux Toolkit
- React Router
- React Icons
- React Toastify
